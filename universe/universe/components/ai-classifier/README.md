# Компоненты ИИ-классификации

## Структура

### Страницы

1. **`/app/ai-classifier`** - Главная страница со списком проектов
2. **`/app/ai-classifier/project/[projectId]`** - Список версий проекта
3. **`/app/ai-classifier/project/[projectId]/version/[versionId]`** - Страница классификации версии

### Компоненты

1. **`ClassificationTable`** - Таблица с результатами классификации
   - Отображение TOP-3 предложений для каждого элемента
   - Поиск и фильтрация по confidence
   - Подтверждение/изменение/отклонение классификации
   - Массовые действия

## Функциональность

### Основные возможности

- ✅ Запуск классификации для версии проекта
- ✅ Отображение результатов с TOP-3 предложениями
- ✅ Фильтрация по confidence (минимальный порог)
- ✅ Поиск по ID элемента, категории, коду СВОР
- ✅ Подтверждение классификации (TOP-1)
- ✅ Изменение классификации (выбор другого предложения)
- ✅ Отклонение классификации
- ✅ Массовое подтверждение/отклонение

### Отображение информации

Для каждого элемента показывается:
- Element ID
- Категория
- TOP-3 предложения с:
  - Рангом (#1, #2, #3)
  - Кодом и названием СВОР
  - Confidence (final_score)
  - Semantic similarity
  - Structured boost (если есть)

### Цветовая индикация confidence

- 🟢 Зеленый: ≥ 80% (высокая уверенность)
- 🟡 Желтый: 60-80% (средняя уверенность)
- 🔴 Красный: < 60% (низкая уверенность)

## API интеграция

Все запросы идут через `lib/api/ai-classification.ts`:
- `runClassification()` - запуск классификации
- `getClassificationResults()` - получение результатов
- `confirmClassification()` - подтверждение
- `changeClassification()` - изменение
- `rejectClassification()` - отклонение

## Важные замечания

⚠️ **Автоклассификация. Требует подтверждения пользователя.** - это обязательное предупреждение, которое должно отображаться на всех страницах классификации.

Все изменения фронтенда разворачиваются только на **dev сервер**.
